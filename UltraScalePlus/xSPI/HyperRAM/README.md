# xSPI HyperRAM Design Tutorials

***Version: Vivado 2026.1***

## Overview

xSPI HyperRAM™ is a JEDEC-compliant serial memory solution that delivers high bandwidth with a low pin count and simple system integration. It provides a cost-efficient and power-efficient external RAM option for FPGAs and edge systems, enabling high-performance memory without DDR complexity.

These tutorials demonstrate how to use the AMD AXI xSPI IP to connect to external HyperRAM devices on the SCU35 evaluation board (Spartan™ UltraScale+™ `xcsu35p` FPGA).
